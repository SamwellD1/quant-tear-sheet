# Quant Tear Sheet

A performance analysis tool built with CAPM, Fama-French 3 & 5-factor regressions, 
drawdown analysis, and rolling Sharpe ratios, benchmarked against the S&P 500.

## Contents
- `tear_sheet.py` — full analysis script
- `tear_sheet_report.html` — generated report (open in any browser)
- `tear_sheet_report.pdf` — PDF version of the report
- 'tear_sheet_notes.pdf' - notes written by me, as I dove deeper into each analysis tool
